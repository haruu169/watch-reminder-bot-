\# Watch Reminder Bot ⌚



Telegram-бот-напоминалка. Присылает уведомления, которые дублируются на смарт-часы.



\## Установка

1\. git clone git@github.com:haruu169/watch-reminder-bot.git

2\. cd watch-reminder-bot

3\. python -m venv venv

4\. source venv/Scripts/activate  # Для Windows (Git Bash)

5\. pip install -r requirements.txt

6\. Создать файл .env со строкой: BOT\_TOKEN=ваш\_токен\_из\_BotFather

7\. python bot.py



\## Использование

/remind 15:30 сдать отчёт — пришлет напоминание в 15:30.



\## Демо

Бот успешно протестирован, уведомления мгновенно приходят на экран смарт-часов.
